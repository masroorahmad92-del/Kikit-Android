# Play Store listing assets

Place exported assets here before uploading to Google Play Console.

## Required files

| File | Size | Notes |
|------|------|-------|
| `icon-512.png` | 512×512 | App icon — export from iOS 1024×1024 asset, resize |
| `feature-graphic.png` | 1024×500 | Banner for store listing |
| `screenshots/phone/` | 2–8 images | 9:16 or 16:9 phone screenshots |

## Screenshot order (match App Store)

1. Live Rooms
2. Discover / Sparks
3. Face verification
4. In-room gifting
5. Chat

See `GOOGLE_PLAY_SUBMISSION.md` for full specs and copy-paste store listing text.
